# Legacy code

This directory contains pre-rebuild SoC Proxy research code retained for
reference only. It is intentionally outside the active `scripts/` and `src/`
trees so that obsolete dispatch, clustering, optimisation, plotting, and
analysis paths do not appear to be part of the current implementation.

Code should only be moved back into the active tree when it is deliberately
reused in the rebuilt paper workflow. Prefer implementing a fresh, narrowly
scoped module and consulting these files for historical logic rather than
reviving the old architecture wholesale.
